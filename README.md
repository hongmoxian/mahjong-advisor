# 麻将出牌助手 (mahjong-advisor)

用摄像头看着手机上的麻将游戏(如王者荣耀里的王者麻将、欢乐麻将等**娱乐模式**, 非赌博),
实时识别你的手牌和场上已打出的牌, 提示你下一张怎么打: 打哪张、听什么、进张还剩多少、
什么时候该防守。

> 仅供学习和娱乐参考。请遵守所玩游戏的用户协议; 麻将有运气成分, 工具只能提高决策质量, 不能保证赢。

## 工作原理

```
摄像头/截图 ──> 识别(轮廓找牌 + 模板匹配) ──> 手牌(13/14张) + 牌河已现牌
                                                    │
                                          麻将引擎 (mjengine)
                                          ├─ 向听数 (距离听牌还有多远)
                                          ├─ 进张数 (打某张后哪些牌能前进、剩几张)
                                          ├─ 缺一门 (血战/血流: 三门时自动只从最弱一门出)
                                          ├─ 简单防守 (优先打牌河现过的牌)
                                          └─ 和牌判定 (到胡了会直接提醒)
                                                    │
                                          画面叠加显示 / 终端输出建议
```

- **向听数**: 0 = 听牌, -1 前一步 = 已经能胡。
- **进张**: 打出某张后, 摸到哪些牌能让向听数下降, 以及这种牌场上还剩几张(已现的牌会被扣除)。
- **规则**: 默认 `sichuan`(只有万/筒/条, 需缺一门, 支持七对), 可切 `full`(34 种牌, 无缺门逻辑)。

## 安装

**macOS / Linux:**

```bash
cd mahjong-advisor
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

**Windows** (先从 [python.org](https://www.python.org/downloads/) 安装 Python 3.10+, 勾选 "Add to PATH"; 在项目目录打开 PowerShell/CMD):

```bat
py -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

下面命令 macOS 用 `.venv/bin/python`, Windows 用 `.venv\Scripts\python`。

## 快速开始(不需要摄像头, 30 秒体验)

```bash
# 生成一套合成截图 + 模板
.venv/bin/python tools/make_sample.py --out demo

# 直接分析这张"截图"
.venv/bin/python main.py --source demo/sample.png --config demo/config.json --analyze-only

# 或者干脆手动输牌, 立刻得到建议:
.venv/bin/python main.py --manual
手牌> 123m456m789m12p999s
```

牌的写法: `m`=万, `p`=筒(饼), `s`=条(索), `z1..z7`=东南西北白发中。
`123m456m789m12p999s` = 123万 456万 789万 1筒2筒 9条×3。也直接支持中文: `1万2万3万`、`东南西北`。

## 完整流程(摄像头模式)

### 第 1 步: 标定

手机横屏打开麻将游戏, 摄像头正对手机。运行:

```bash
.venv/bin/python calibrate.py
```

1. 按 `c` 冻结画面(画面不动才好框选);
2. 按 `h` 拖框选中**你的手牌一行**, 回车确认;
3. 按 `d` 拖框选中**能看到全部牌河的区域**, 回车确认;
4. 按 `t` 框住**一张牌**(贴边框选), 回车后在终端输入它的代码(如 `5m`), 保存为模板;
   对每种出现过的牌重复(万筒条各数字至少来一张, 建议把 1-9 都截一遍);
5. 按 `s` 保存, `q` 退出。

配置和模板存在 `config.json` 和 `templates/`(相对路径, 在项目根目录运行即可)。macOS 第一次会弹窗要求给终端授权摄像头; Windows 用默认相机应用确认摄像头可用。

### 第 2 步: 对局中使用

```bash
.venv/bin/python main.py            # 默认摄像头
.venv/bin/python main.py --source cam:1
```

窗口里绿色框是手牌区域, 黄色框是牌河区域。快捷键:

| 按键 | 功能 |
| --- | --- |
| 空格 | 立即分析当前画面(摸牌后按一下最合适) |
| `a` | 连续自动分析 开/关 |
| `d` | 防守模式 开/关(有人快胡时打开, 优先打别人现过的牌) |
| `e` | 手动输入手牌(识别不准时的兜底) |
| `x` | 清除手动输入, 回到摄像头识别 |
| `f` | 冻结/继续画面 |
| `q` | 退出 |

面板会显示: 当前手牌、缺门状态、向听数、**★ 建议打哪张**(打后向听 + 进张明细)和备选。

### 没有摄像头也能用于实战

手机截图 → 传到电脑 → 分析:

```bash
.venv/bin/python main.py --source 游戏截图.png --analyze-only
```

(需要先用截图完成第 1 步标定, 模板也从截图里截。)

## 开发与测试

```bash
.venv/bin/python -m pytest tests/ -v     # 引擎单元测试 + 合成画面端到端测试
```

测试里 `tests/synth.py` 会合成假的"手机截图"(白底牌面 + 牌代码)来验证
识别→建议全链路, 不依赖摄像头。

## 已知局限与路线图

- 识别基于模板匹配, 换游戏皮肤/分辨率变化后需要重新截模板; 光线反光、手机斜放都会影响。
  改进方向: 固定三脚架 + 正对屏幕; 后续可换 YOLO 目标检测模型, 一次训练通用。
- 手牌 < 14 张时大部分游戏会压缩间距, 轮廓间距检测可能粘连, 目前靠 `min_tile_area`/`max_tile_area`
  阈值调优, 或用 `e` 手动输牌兜底。
- 未识别副露(碰/杠), 未做对手牌型推断的高级防守(振听/现物), 防守模式只是"优先打现过的牌"。
- 路线图: 语音播报建议、scrcpy/屏幕镜像代替摄像头(更稳)、基于牌河的对手听牌推断、副露识别。

## 项目结构

```
mahjong-advisor/
├── main.py            # 主程序(摄像头/图片/手动模式)
├── calibrate.py       # 交互式标定: 区域 + 模板截取
├── mjengine/          # 纯算法: 牌表示 + 向听/进张/缺门/防守
├── vision/            # 采集、识别(模板匹配)、配置、中文叠加
├── tools/make_sample.py  # 生成合成演示素材
├── tests/             # pytest 测试 + 合成画面生成器
├── templates/         # 你的牌面模板(calibrate.py 生成)
└── config.json        # 你的配置(calibrate.py 生成)
```
